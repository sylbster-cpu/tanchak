# 탄착점

바람을 읽고 각도와 힘을 맞춰 상대 포대를 맞히는 턴제 포격 게임입니다. 브라우저에서 PC와 휴대폰 모두 즐길 수 있습니다.

플레이: https://sylbster-cpu.github.io/tanchak/

## 방식
- 컴퓨터와 대결
- 둘이서 번갈아 (한 기기)
- 과녁 연습

## 기체
방식을 고른 뒤 기체를 고릅니다. 경전차, 중전차, 곡사포, 굴착차가 있고, 체력·한 차례 이동 거리·포신 각도 범위·전용탄이 다릅니다.

## 카드
기본탄은 언제나 쓸 수 있고, 나머지 포탄은 카드로 받습니다. 판마다 덱 7장(대형탄 2, 무풍탄 2, 전용탄 3)에서 손패 3장을 받고, 1장을 쓰면 덱에서 1장을 새로 뽑습니다. 덱이 비면 손패가 줄어듭니다.

## 조작
- PC: ←→ 이동, ↑↓ 각도, 스페이스를 누르고 있다가 떼면 발사, 1 기본탄·2~4 손패, P 넘기기, T 조율판
- 휴대폰: 가로로 눕혀 화면 아래 버튼으로 조작
- 둘러보기: 전장을 끌면 다른 곳을 볼 수 있고, 위쪽 지도를 누르면 그곳으로 갑니다. 전장을 한 번 누르거나 쏘면 다시 따라갑니다.

한 차례는 20초입니다. 센 포탄일수록 딜레이가 커져 다음 차례가 늦게 옵니다. 각도는 탱크 차체를 기준으로 잽니다.

개발 중인 게임이라 규칙과 수치가 계속 바뀝니다.
