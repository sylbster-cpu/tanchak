# 탄착점 (TANCHAK)

바람을 읽고, 한 발로 뒤집다. **탄착점**은 지형을 파괴하며 각도와 파워를 조절해 대결하는 레트로 턴제 포격 게임입니다. PC와 휴대폰 브라우저에서 별도 설치 없이 실행할 수 있습니다.

**플레이:** https://sylbster-cpu.github.io/tanchak/

## 게임 시작

- **AI 대전:** 컴퓨터와 대결합니다. 쉬움·보통·어려움 난이도를 선택할 수 있습니다.
- **둘이서 대전:** 같은 기기에서 번갈아 플레이합니다.
- **연습 사격:** 제한 시간 없이 포탄 궤적과 지형 파괴를 익힙니다.
- **전장 선택:** 무작위, **전선**(완만한 구릉), **협곡**(깊은 계곡), **고원**(높은 능선). 전장에 따라 이동과 사격에 유리한 위치가 달라집니다.

## 탱크

| 탱크 | 특성 | 전용탄 |
| --- | --- | --- |
| **스카우트** | 빠른 이동과 넓은 조준각 | 도약탄 |
| **타이탄** | 높은 체력과 강한 직격 공격 | 철갑탄 |
| **코멧** | 고각 사격에 유리 | 분열탄 |
| **드릴러** | 비탈을 잘 오르고 지형을 파괴 | 굴착탄 |

기본탄은 무제한이며, 대형탄·무풍탄·전용탄은 한 판당 각 2발입니다. 다른 탱크를 선택하면 이동력, 체력, 조준각, 턴 딜레이가 달라집니다.

## 조작과 규칙

- **PC:** `← →` 이동, `↑ ↓` 조준각, `1~4` 포탄, `C` 아이템, `P` 턴 넘기기, `T` 설정. `Space`를 길게 누르고 원하는 파워에 떼면 발사합니다.
- **휴대폰:** 화면을 가로로 놓고 아래 이동·조준·포탄·발사 버튼을 사용합니다. **발사 버튼은 누르고 있다가 떼세요.** 짧은 탭은 발사되지 않습니다.
- **카메라:** 전장을 끌거나 미니맵을 눌러 둘러봅니다. 전장을 한 번 누르거나 발사하면 다시 전투를 따라갑니다.
- **승리:** 상대의 체력을 모두 없애거나 맵 아래로 떨어뜨리면 이깁니다.
- **턴:** 기본 20초 제한. 남은 **딜레이**가 적은 탱크가 다음 턴을 갖습니다. 강력한 포탄, 추가 효과, 조준에 쓴 시간은 딜레이에 영향을 줍니다.
- **아이템:** 끌어오기와 **탄착 이동**은 선택한 포탄에 효과를 더합니다. 한 턴에 하나를 지정할 수 있습니다. 탄착 이동은 포탄이 떨어진 위치로 자신의 탱크를 옮깁니다.

화면의 **조준각**은 차체를 기준으로 측정하므로 비탈에 서면 실제 발사각이 달라집니다.

## 개발 및 검증

게임을 배포할 때는 루트의 **`index.html` 하나만 있으면 됩니다.** 편집은 `src/` 폴더에서 하고 빌드해 최종 HTML을 만듭니다.

```sh
python scripts/build.py
python scripts/build.py --check
```

작업 환경에 Python 3과 Playwright/Chromium이 있으면 다음 검사를 실행할 수 있습니다.

```sh
python tests/qa_tanchak.py
python tests/soak_quality.py 150000
```

검사는 브라우저에서 `?test` 테스트 인터페이스를 이용합니다. 화면 검사는 Google Fonts 없이 진행되므로 실제 폰트 및 휴대폰 브라우저에서의 입력 지연·성능은 별도로 확인해야 합니다. 현재 삼성 인터넷 실기기 검증은 완료되지 않았습니다.

배포 정책: 큰 변경은 별도 브랜치에서 검토 후 `main`에 병합합니다. `main`의 루트에서 GitHub Pages가 배포됩니다.
